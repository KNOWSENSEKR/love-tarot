# 🔮 마음코드: 상대방 속마음 타로

> **"잘해줬는데 왜 차였을까?"**  
> 그 해답을 심리학적 타로 알고리즘으로 분석해 드립니다.

![타로 미리보기](https://knowsensekr.github.io/love-tarot/back.png) <!-- 필요시 실제 스크린샷으로 교체 -->

## 📌 프로그램 소개

이 프로그램은 단순한 점술이 아닙니다.  
**심리학의 '희소성 원리'와 '간헐적 강화' 이론**을 바탕으로,  
현재 주인님과 상대방의 심리적 위치를 정확히 분석하고  
**연애 주도권을 되찾는 실전 전략**을 제시합니다.

### ✨ 주요 특징
- Major Arcana 22장 전체 사용 (연애운 특화 해석)
- 과거 · 현재 · 미래 3장 동시 리딩
- 심리학 기반 맞춤 연애운 + 솔루션 제공
- 모바일에서도 편안한 반응형 디자인
- 마음코드 구독자 전용 **무료 타로 웹앱**

## 🚀 바로 사용하기

👉 **[타로 프로그램 열기](https://knowsensekr.github.io/love-tarot/)**

**사용 방법**
1. 마음을 가다듬고 상대방을 떠올립니다.
2. **"새로운 타로 3장 펼치기"** 버튼을 클릭하세요.
3. 카드가 뒤집히며 **과거·현재·미래** 연애운이 나타납니다.
4. 아래에 나오는 **심리학적 솔루션**을 실천해 보세요.
